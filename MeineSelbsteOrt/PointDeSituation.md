# Point de situation

On a découvert la généricité, l'importation depuis un fichier externe CSV et les fonctions d'ordre supérieur. On a développé l'exercice "ESportApp" où l'on a pratiqué les connaissances apprises :
- 2.0 `DataSeries<T>` générique avec stockage immuable
- 2.1 Parser les fichiers CSV (`FromCsv`)
- 2.1 Générer des matchs avec `Enumerable.Range` (`MatchGenerator`)
- 2.2 Sauvegarder les données en CSV
- 2.3 CLI pour demander la génération (`--generate <joueur|all>`)
- 2.4 Filtrage des données selon des critères métier (`Filter`)
- 3.1 Détecter les erreurs en implémentant `.Outliers(predicate)`
